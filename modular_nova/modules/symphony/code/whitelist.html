/tg/ Station 13 - Modules - Types

modular_nova/modules/symphony/code/whitelist.dm

/proc/symphony_has_ingame_roleQuery a linked account for an in-game role grant. Returns TRUE/FALSE, or null when the database cannot answer. Unlinked accounts return FALSE.
/proc/symphony_ingame_role_ckeysReturn role holders as ckey -> TRUE, an empty list for no holders, or null on query failure.
/proc/symphony_invalidate_whitelist_cacheInvalidate one account immediately after a role change.
/proc/symphony_seed_whitelist_cacheCache a confirmed TRUE/FALSE result from a notification or bulk query. Advancing the epoch prevents an older in-flight query from overwriting this answer.
/proc/symphony_whitelist_cache_peekReturn cached TRUE/FALSE, or null for a miss. Never queries or sleeps.
/proc/symphony_whitelist_lookupReturn a cached whitelist answer, querying on a miss. May sleep. Database failures return null and are never cached; FALSE is a confirmed denial. Use symphony_whitelist_cache_peek() in display and signal handlers that cannot sleep.
/proc/is_symphony_whitelistedAdmission check: allow access when enforcement is disabled; deny on a database failure. Use symphony_whitelist_lookup() when the caller must distinguish a denial from an outage.
/proc/symphony_holds_whitelist_roleCheck a current role entitlement, bypassing the admission cache. Unlike admission, perks and imports require an enabled module and a confirmed grant.
