What the club mirror on the Markings tab needs beyond the markings data: the colour each marking starts in, the custom drawings to show on its cards, which body region owns each pixel of the drawn character, and a surprise. See module.md.

proc
augment_overlay_map
(/mob/living/carbon/human/body, width)

The visible augments the preview body wears, mapped as its regions are (custom_sprite_region_map()): which one draws each pixel, facing each way. A pair of eyes, an implant's overlay: the scan chamber's x-ray leaves each showing as it is, in its own shape. Each one's images are filled with its ID colour and composed in draw order, and the result is read once per view. Cached by the images that drew it.

Arguments:

  • body: The preview body.
  • width: The canvas width, as the body's region map has it.

Returns list("zones" = the augments' slots, "rows" = facing -> 32 row strings), or null when none draws.
