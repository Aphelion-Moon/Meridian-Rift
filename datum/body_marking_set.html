body_marking_set
/datum/body_marking_set

Vars

body_marking_listThe markings this set puts on, as /datum/body_marking typepaths, in the order they go on.
keep_togetherWhether picking this set in character setup replaces every marking with the set's, as a unit. Otherwise the set replaces only the zones it covers and every other zone keeps its markings.
nameThe preview name of the body marking set. HAS to be unique
recommended_speciesThe species this set is meant for, species id -> TRUE, or null for any species: the ones a random character may draw it for, and without mismatched parts the only ones character setup offers it to. Each of its markings may be worn by at least these, as derive_body_marking_species() gives a marking the species of its sets.

Procs
