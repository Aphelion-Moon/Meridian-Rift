dirt_masks
/datum/dirt_masks

A surface's masks: its mess baked into four-direction RGBA icons (dirt_baked_icon()), registered in the resource cache, each drawn as it is (dirt_mess_baked_image()).

Vars

bakedFor cloth: the baked icon on the whole canvas, which the garment's own pixels clip. For a part, the same, already kept to the part's pixels. Null when it draws nothing.
baked_by_layerFor a taur body's pools: alist(EXTERNAL_* layer = baked icon), each on the taur canvas, kept to the pixels that layer shows (dirt_taur_owners()). A taur suit draws them from baked, over the whole canvas.
baked_by_limbFor skin: alist(limb zone = baked icon), each limb's clipped to the pixels its image shows.
keyThe request's mask_key().
limb_keysFor skin: alist(limb zone = an MD5 of what its baked icon draws, dirt_runs_key()), so only a limb whose pixels changed caches new images.
