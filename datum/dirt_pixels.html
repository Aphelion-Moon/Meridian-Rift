/tg/ Station 13 - Modules - Types — Var Details - Proc Details

dirt_pixels
/datum/dirt_pixels

A raster's or a mask's pixels: a tone role and a thickness for each. Lists are indexed y * width + x + 1 in the reference generator's coordinates, as a /datum/dirt_surface's are: x from the left and y from the top, both from 0.

Vars

coversWhether it covers, so that where splats merge it keeps every piece (dirt_merge()). Mess at the top level covers, and so does every part's field (dirt_part_field()).
drawn_indexesEvery pixel drawn, where it's kept, so a walk that doesn't depend on order visits those pixels alone. They're in the order drawn. A pixel cleared since is still listed, and one drawn again after a clear is listed twice. Null where it isn't kept, and then the walk takes the whole canvas. A merge, a deposit's levels and their stack keep it, and a copy keeps its original's. A decoded raster lists its pixels in row-major order (dirt_pixels_from_drawn()), on a deposit's limbs alone where it's decoded to them. Every writer lists a blank pixel it draws. A walk in row-major order goes from the lowest index to the highest (drawn_span()).
heightPixels down.
materialsEach drawn pixel's material, as a splat stores it (/datum/dirt_splat/var/material), where dirt_merge() was given materials. Null where it's all one material. A raster's material is its deposit's own. A merge's null means the surface's only material is mess (dirt_splat_materials() gives null for mess alone), and runs and the bake read it that way.
rolesEach pixel's DIRT_ROLE_* define, or null where nothing is drawn.
thicknessesEach drawn pixel's thickness, from 0 to 1. Where rasters merge, the thicker one wins a pixel its role ties on.
widthPixels across.

Procs

copyReturns a copy, with its own lists.
drawnReturns its drawn pixels alone, packed as text, which is all a cached raster keeps: "1" if it covers, else "0", then its drawn pixels in row-major order, a run at a time. A run is pixels side by side in one role and thickness. Each run is four base-64 digits ("0" to "o") holding 24 bits (DIRT_PACKED_RUN()): its first pixel's index - 1 in 11, its length - 1 in 6, its role in 3 and its thickness's code in 4 (dirt_thickness_code()). Every run is as long as it goes, up to 64 pixels, so the same pixels always pack as the same text. 11 bits hold indexes up to 2048, the size of the 64x32 taur canvas, and every canvas fits in that. A bigger canvas can't be packed. Only this proc writes the text, and DIRT_PACKED_BITS() and the fields after it read it back.
drawn_spanReturns the first and the last pixel a walk in row-major order needs to meet every drawn pixel, list(first, last). Where drawn_indexes is kept, they're the lowest and the highest index it lists, or the last comes before the first if it lists none. Where it isn't kept, they span the whole canvas.
grid_textReturns the pixels as text, one line per row joined by newlines, one glyph per pixel: "." none, "h" haze, "f" film, "b" body, "c" core, "k" fleck, "g" glint.
put_indexDraws a role on a pixel by its index. Where drawn_indexes is kept, a blank pixel it draws joins the list.
walk_indexesReturns the pixels a walk that doesn't depend on order visits: drawn_indexes where they're kept, else every index. You should NEVER modify it.

put_index
(index, role, thickness)

Draws a role on a pixel by its index. Where drawn_indexes is kept, a blank pixel it draws joins the list.

Arguments:

  • role: A DIRT_ROLE_* define, or null to clear it.
  • thickness: How thick it lies, from 0 to 1.
