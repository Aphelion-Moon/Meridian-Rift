dirt_feature
/datum/dirt_feature

One mark a cause leaves on a body's surface: how thick it lies at each point of one limb, from 0, nothing, to 1. Only a contact point or a wet coat's underside passes DIRT_CONTACT, so the darkest role lands there and nowhere else.

A feature also knows how far it can reach, so it's weighed only on the pixels round it. A few are drawn on pixels each view picks for them instead (bind()).

Procs

bindWorks out the pixels the feature draws on in one view, into drawn_pixels. By default it takes its thickness() on each pixel of its limb it can reach. A few pick their pixels instead. Every pixel's theta lies within 90 degrees of the way the view faces (/datum/dirt_surface/proc/place_pixels()). So if a view faces more than 90 degrees past a feature's reach, it shows none of the feature, and no pixel is weighed.
noiseReturns two octaves of value noise at a point, as dirt_spread_noise() does. With its mask job's table (deposit_samples), it returns the value kept there for the same four numbers, or samples one now and keeps it. The table keys the four numbers exactly. In one drafting state (SSdirt.drafting) the noise depends on its arguments alone, and a job draws every direction of a deposit while drafting. So a kept value is what sampling again returns.
pixels_onReturns how thick the feature lies on each pixel of the view it's drawn on, where it lies at all: alist(pixel index = thickness). It's worked out the first time it's asked for (bind()). A feature is drawn on one view at a time, and unbind() frees it for the next. You should NEVER modify it.
set_reachSets how far the feature can reach: across_px either side of theta round the limb, and from down_px under along to up_px over it.
thicknessReturns how thick the feature lies at a point of the surface, from 0, nothing, to 1.
unbindFrees the feature for another view. It drops what it bound on the last view and the part of its job's noise table it read. It binds again on the next view when asked (pixels_on()). The rest of what it was made with stays, because a mask job draws a deposit's features in each direction in turn (dirt_level_features()).

bind

Works out the pixels the feature draws on in one view, into drawn_pixels. By default it takes its thickness() on each pixel of its limb it can reach. A few pick their pixels instead. Every pixel's theta lies within 90 degrees of the way the view faces (/datum/dirt_surface/proc/place_pixels()). Arguments:

  • surface_rows: Its pixels by limb and row, from dirt_surface_rows().

proc
noise
(sample_x, sample_y, seed, scale)

Returns two octaves of value noise at a point, as dirt_spread_noise() does. With its mask job's table (deposit_samples), it returns the value kept there for the same four numbers, or samples one now and keeps it. The table keys the four numbers exactly. In one drafting state (SSdirt.drafting) the noise depends on its arguments alone, and a job draws every direction of a deposit while drafting. So a kept value is what sampling again returns.

Arguments:

  • sample_x, sample_y, seed, scale: As dirt_spread_noise()'s.

Arguments:

  • surface_rows: Its pixels by limb and row, from dirt_surface_rows().
