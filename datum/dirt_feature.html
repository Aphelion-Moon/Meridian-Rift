dirt_feature
/datum/dirt_feature

One mark a cause leaves on a body's surface: how thick it lies at each point of one limb, from 0, nothing, to 1. Only a contact point or a wet coat's underside passes DIRT_CONTACT, so the darkest role lands there and nowhere else.

A feature also knows how far it can reach, so a mask weighs it only on the pixels round it. A few are drawn on pixels each view picks for them instead (bind()).

New
(limb)

Starts a feature on a limb.

Arguments:

  • limb: The DIRT_LIMB_* define it lies on, or null for one drawn on pixels a view picks across limbs.

proc
bind
(/datum/dirt_surface/surface, /alist/surface_rows)

Works out the pixels the feature draws on in one view, into drawn_pixels: by default its thickness() on each pixel of its limb it can reach. A few pick their pixels instead.

Arguments:

  • surface: The view's surface.
  • surface_rows: Its pixels by limb and row, from dirt_surface_rows().

proc
pixels_on
(/datum/dirt_surface/surface, /alist/surface_rows) as /alist

Returns how thick the feature lies on each pixel of the view it's drawn on, where it lies at all: alist(pixel index = thickness), worked out the first time (bind()). A feature is drawn on one view only. You should NEVER modify it.

Arguments:

  • surface: The view's surface.
  • surface_rows: Its pixels by limb and row, from dirt_surface_rows().

proc
thickness
(theta, along)

Returns how thick the feature lies at a point of the surface, from 0, nothing, to 1.

Arguments:

  • theta: Degrees round the limb, from -180 up to 180.
  • along: h along the limb.
