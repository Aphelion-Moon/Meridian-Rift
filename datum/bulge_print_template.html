bulge_print_template
/datum/bulge_print_template

A bulge shape template decoded for printing: which kind of pushed-out cloth sits at each pixel facing south, east and west (nothing prints facing north). Decoded once per template from a kind map in the template sheets by bulge_decode_template(), or past small_cap derived from the game's sprites (templates.dm), and kept in GLOB.bulge_print_templates.

Vars

clippedWhat covers draw over their sprites kept to this shape's pixels (bulge_clipped_icon()): sprite -> state -> registered icon, or FALSE when nothing could be kept. Lazy.
eastKind pixels facing east, as south.
iconThe template sheet it was decoded from; null for a derived template.
icon_stateIts state in that sheet, or the name it was derived under.
keyThe template's name, unique per shape; part of every patch's cache key.
mask_clothThe white masks an adaptive bulge of this shape draws, one per kind, and of all its kinds together for its emissive blocker: registered icons, FALSE for a kind it has no pixels of, null until bulge_template_masks().
mask_deep_shadeAs mask_cloth, for BULGE_KIND_DEEP_SHADE.
mask_highlightAs mask_cloth, for BULGE_KIND_HIGHLIGHT.
mask_lightAs mask_cloth, for BULGE_KIND_LIGHT.
mask_shadeAs mask_cloth, for BULGE_KIND_SHADE.
mask_unionEvery kind together.
southKind pixels facing south: flat (column, row, kind) triples, columns and rows from 0 at the top left. Null if none.
westKind pixels facing west, as south.
