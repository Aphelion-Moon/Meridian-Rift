proc
build_subtler_targets
(/mob/user, subtler_range, /list/portal_device_refs)

Builds the Subtler target menu for user, as display name -> weak reference.

Kept in its own proc so everything it walks is released the moment it returns, rather than sitting in a local and holding candidates alive across the prompt that consumes the result.

Arguments:

  • user: Whoever is sending the Subtler.
  • subtler_range: How far away anyone outside a portal device link can be.
  • portal_device_refs: Gets the menu name of each person on the far end of a portal device link, however far away, mapped to a weak reference to the device. They show as Unknown unless user can see them and their end isn't anonymous.

proc
portal_device_candidates
(/mob/living/user)

Returns every portal device that could link user to someone on its far end, each once.

That's every device user carries or stands within a tile of, plus the device linked to any receiver that user wears. far_end_partner() decides whether each link is actually open.

proc
portal_device_place
(/mob/living/carbon/human/user, /obj/item/clothing/sextoy/portal_fleshlight/device)

Returns a short note on how user is linked to the device, so two links that both show Unknown can be told apart.

That's the slot user wears the device's receiver in, the hand they hold the device in, that they carry it packed away, the floor, or whoever next to them holds it.

proc
send_device_subtler
(/mob/user, /obj/item/clothing/sextoy/portal_fleshlight/device, /mob/living/carbon/human/partner, subtler_emote, running_emote_type, space, sender_message)

Delivers one Subtler through a portal device to the person offered on its far end.

The far end sees it marked as coming through the portal. It's signed with the name anyone looking at the sender would see, or Unknown while the sender's end is anonymous.

Arguments:

  • user: Whoever is sending it.
  • device: The device linking the two ends.
  • partner: The person offered on the far end. Nothing is sent once the link no longer reaches them.
  • subtler_emote: The emote as typed.
  • running_emote_type: The emote's type flags.
  • space: What goes between the sender's name and the emote.
  • sender_message: The sender's own copy, already formatted.
