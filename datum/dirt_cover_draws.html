/tg/ Station 13 - Modules - Types — Var Details

dirt_cover_draws
/datum/dirt_cover_draws

Every random draw a plunge or a blast makes, whatever its level, in the reference generator's order. Anything else drawn from the same field makes them on the same stream (dirt_cover_draws()), so a coat's line meets across shapes.

Vars

facingThe theta a blast comes from: the front most often, or 60 degrees to either side.
kept_runsThe short runs of thicker material down a plunge's coat, each list(pixels across, top in pixels up, length). Of the five drawn, one within 3 px across of an earlier run is left out. The two would join into one line that reads as a strap.
linesThe coat's line at each level, in pixels over the floor: knee-deep, chest-deep, over the head.
runs_atalist(pixels across = the kept run within half a pixel of it, or FALSE for none). Each is found the first time a plunge's coat is asked about a point there (dirt_plunge_thickness()). Kept runs lie 3 px apart, so there's one at most. A point lies in a column's middle on every canvas, so it holds 64 entries at most.
seedThe seed of the coat's noise, a whole number.
shineWhere a wet coat catches the light, each list(pixels across, pixels up).
tiltHow many pixels the line climbs from the tile's middle to 16 px across, either way.
