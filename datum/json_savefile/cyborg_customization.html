cyborg_customization
/datum/json_savefile/cyborg_customization

The account's cyborg layout sidecar, cyborg_customization.json beside preferences.json, keyed by character slot.

Vars

preferences_refThe preferences that own this store, so a finished write can tell their editor
read_refusedThe file on disk was past CYBORG_LAYOUT_MAX_SIDECAR_BYTES, so it was not read and is never overwritten.

write_oversizedThe last write was refused because the whole tree encodes past CYBORG_LAYOUT_MAX_SIDECAR_BYTES.
