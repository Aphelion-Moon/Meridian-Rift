dirt_test
/datum/unit_test/dirt_test
inherits /datum/unit_test/portal_test

The dirt tests that draw dirt on bodies, with the helpers they share: genitals built from DNA as a real character's, taurs, and reads of what a body draws.

row_shown
(/icon/map, size, row)

Returns the row, from the top, that a height map shows on a row of a sprite. The map tells each row which row it shows by its green channel down its middle, rounded to the nearest row. 128 shows its own row, 0 the row a size above, and 255 the row a size below.

Arguments:

  • size: Its displacement filter's size.
  • row: The row, from the top.
