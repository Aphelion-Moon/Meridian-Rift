graffiti_library_caps
/datum/unit_test/graffiti_library_caps

A library holds GRAFFITI_LIBRARY_CAP pieces and the Unfinished slot through a reload from its file. Each write paces the account's next player write by its cost. At the cap it refuses a new piece and a Keep but still replaces a saved piece, and a stored piece that no longer validates is dropped when the file loads. The library loaded after a purge is empty under a newer revision, so a window still showing the purged one is sent the empty one.
