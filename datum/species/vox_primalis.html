proc
on_bodypart_updated
(/mob/living/carbon/human/source, /obj/item/bodypart/limb, dropping_limb, is_creating)

Gives Vox Primalis limbs the sprite set picked by the vox_bodycolor feature.

Runs whenever a limb is created or rebuilt from DNA, so species changes, regrown limbs and the preferences preview all pick it up. Limbs that aren't using a Vox Primalis sprite set are left alone.
