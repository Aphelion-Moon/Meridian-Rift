cyborg_model_gallery
/datum/asset/cyborg_model_gallery

Public stock artwork is encoded once per catalog generation, independently of private layouts. Keep file resources and small indexes, not duplicate JSON lists.

Vars

assetsOwned resources are registered only on acquisition, avoiding global preloading.
catalogThe model catalog the gallery was last built from
catalog_assetAsset name of the gallery's model list
department_assetsAsset name of each department's thumbnails, by department
generatingWhether or not a build is running, so everyone else waits for it
generationHash of the gallery's contents, which names its asset files
generation_failureThe exception the running or last build threw, thrown again to everyone who waited on that build

Procs

assets_for_departmentUnknown departments select only the finite catalog, never a new resource.

ensure_readyWaits out a running build, and throws again whatever that build threw
