Proc Details

proc
burn_fire_run
()

Burns the fire run's tiles, as many as the tick allows.

Hosts going out meanwhile hand their block lights over once per block: here when the run stops for the tick, in the light pass right after the run when it ends.

Returns:

  • TRUE: The run is done.
  • FALSE: It stopped for the tick and carries on next fire.

proc
get_fire_block
(/turf/tile) as /turf

Returns the bottom-left turf of the 2x2 fire light block holding a turf.

Blocks are world-aligned per z and start on odd x and y (1-2, 3-4, ...), so a block's bottom-left turf always exists.

Arguments:

  • tile: Any turf.

proc
get_fire_block_burning
(/turf/block, /list/burning_by_block) as /list

Returns the burning liquids on a fire light block's tiles.

Arguments:

  • block: The block's bottom-left turf. Null, for a block off the map, has none.
  • burning_by_block: Earlier results to reuse and add to, by block. Only valid while no fire state changes.

proc
get_pool_alpha
(liquid_state, opacity)

Returns the alpha for a liquid pool.

A clear pool takes its depth's entry in clear_alpha_by_state, so deeper liquid reads stronger. Opacity blends that toward 255, so a fully opaque mix hides the floor at any depth.

Arguments:

  • liquid_state: The pool's LIQUID_STATE_* depth. Null counts as a puddle.
  • opacity: Volume-weighted liquid_opacity of the pool's reagents, 0 to 1.

proc
hand_over_fire_lights
(/list/burning_by_block)

Gives each block whose light host went out during the fire run a new host, from what burns on it now.

Arguments:

  • burning_by_block: The get_fire_block_burning() results to reuse and add to.

Returns the blocks it worked out, as an assoc list.

proc
keep_fire_holder
(/obj/effect/abstract/liquid_fire/holder, /list/pool)

Keeps a fire holder that left its tile for reuse, stamped with the time it left, or deletes it when its pool is full.

Arguments:

  • holder: The holder, already out of its liquid's vis_contents.
  • pool: The pool of its kind.

proc
mark_fire_block
(/turf/tile)

Queues the fire light block holding a turf for the next light pass.

proc
release_fire_light
(/obj/effect/abstract/liquid_turf/liquid)

Takes the block light off a liquid, if it holds one, hands it to another burning tile of the block, and queues the block so the next light pass updates its neighbours.

Call it when a burning liquid stops burning, leaves its turf or is deleted, and only once the block scan can no longer see it there: after its fire_state is NONE, or after its turf's liquids is cleared. Inside the fire run the hand-over waits until the run stops for the tick, so a pool burning out at once is relit one block at a time, not once per tile.

Arguments:

  • liquid: A liquid on a turf.

proc
take_fire_holder
(/list/pool) as /obj/effect/abstract/liquid_fire

Returns a fire holder from a pool, or a new one when the pool has none released before this tick. The caller sets everything a holder shows.

A holder released this tick is never handed out: until the tick ends, a client can draw its new look at its old tile. Pools are in release order, so only the newest and the oldest need checking.

Arguments:

  • pool: fire_flame_pool, fire_glow_pool or fire_smoke_pool.

proc
update_fire_block
(/turf/block, /list/burning_by_block)

Gives a fire light block one light, on the burning liquid nearest the centre of its burning tiles, or no light when nothing on it burns.

The light sits at that centre. Its range and power follow the block's largest flames, and its power is shared out with every burning block around it.

Arguments:

  • block: The block's bottom-left turf.
  • burning_by_block: The pass's get_fire_block_burning() results so far, filled in as blocks are read.

proc
update_fire_lights
(tick_checked)

Relights the fire light blocks queued since the last pass, and the 8 neighbours of each that started or stopped burning, whose power depends on how many blocks around them burn. Blocks whose host went out in the fire run get their new host first.

Every block is worked out at most once per call, from what burns on it now, however often its tiles changed. So a pass does at most nine blocks of work per queued block, and blocks queued while it runs wait for the next pass.

Arguments:

  • tick_checked: TRUE in fire(), where the pass stops when the tick runs out and carries on next fire. FALSE runs a stopped pass and everything queued to the end now.

Returns:

  • TRUE: The pass is done.
  • FALSE: It stopped for the tick.
