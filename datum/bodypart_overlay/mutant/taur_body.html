proc
dirt_pools_carrier
(/obj/item/bodypart/limb, /datum/component/dirtiness/carrier) as /datum/component/dirtiness

Returns the carrier of the taur body's dirt, or null if the body has none or can't draw it (dirt_read_source()). Both icon_render_key() and get_overlay() ask this proc, so the dirt drawn always matches the key. Dirt drawn under a key that didn't name it would be cached for every body that draws alike.

Arguments:

  • limb: The chest it's drawn on.
  • carrier: The dirtiness component of the chest's owner, or null if it has none.
