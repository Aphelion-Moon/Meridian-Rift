modular_aphelion/modules/character_preview/code/effects.dm

/proc/character_preview_effectsWhat the page draws over the character preview's drawing, because a flatten leaves it out: the rows tg's height filters move, and the mob's transform (body size). Takes the drawing's frame height and how far its tile sits above the frame's bottom (the "y" the page gets). Returns the page's keys for them, left out when the mob has neither:
/proc/character_preview_rowsThe runs of frame rows that the mob's displacement filters move, as character_preview_effects() gives them, or null if there are none or one moves more than whole rows. Filters run in the order tg keeps them, each map centred on the tile and then moved by its own offset. The page moves the tile's columns, so each map must cover them.
/proc/character_preview_body_rowscharacter_preview_rows() worked out from the body's filter_data, uncached.
/proc/character_preview_map_rowsHow a displacement map moves each of its rows, and how wide it is: list(moves, width), the moves from the bottom, -1 when a row shows the row below, 1 the row above, 0 itself. FALSE for a map whose rows don't each move whole and as one. tg's heights use a handful of shared maps, tiled three wide (wide_height_map()), so each is read once.
/proc/character_preview_height_mapA height map as it lies on an image width by height, centred on it and then moved by the filter's own offset: list(its rows' moves as character_preview_map_rows() gives them, size, its bottom row, its left column, its right column), in the image's own pixels from its lower left (1, 1). Null for a map that moves more than whole rows.
/proc/character_preview_flat_heightA flat icon with the height filters of the image it was drawn from drawn in, as the game draws a body that stretches each of its images: each row its maps move shows the row they take it from, across the columns they cover. get_flat_uni_icon() calls it, when the preview asks (character_preview_flatten()), for an image below the one it flattens, with the image's own icon, or with all of it when it keeps its overlays together, as far as BYOND's filters reach. The look's own filters are the page's (character_preview_rows()).
/proc/character_preview_clear_coloursA flat icon's own transforms, when they are all colours that leave a clear pixel clear (a multiply, or a colour matrix with no alpha of its own), so it can be stretched bare and coloured after. The rows a stretch adds and clears stay clear either way. An empty list for a bare sprite, null for anything else, like a flat with overlays drawn in.
/proc/character_preview_height_planWhat character_preview_flat_height() moves for an image's height filters on a canvas box, counted as character_preview_flat_box() counts it: list(the lowest row drawn, the highest, the maps' left column, their right column, the moved runs, each list(bottom row, top row, the row its bottom lands on), and the runs of the canvas's own rows to clear under them, each list(bottom row, top row)). Null for maps that move more than whole rows, or move columns of their own, or nothing on the canvas.
/proc/character_preview_map_pixel_moveHow one displacement map pixel moves its row: -1, 0 or 1 as character_preview_map_rows() has them, or null when it moves it sideways or by part of a pixel.
