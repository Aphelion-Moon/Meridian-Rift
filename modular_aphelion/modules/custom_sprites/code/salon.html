/proc/custom_sprite_salon_previousStyle key -> a copy of the look each of a target's drawings had before its last salon change, for those that have one. keys limits it.
/proc/custom_sprite_salon_restore_choicesWhat Restore previous offers for several previous looks: the whole body, then each region by name. Label -> style keys.
/proc/custom_sprite_salon_export_liveSends a player their own live look for a salon target: one file for hair, a whole-body file for a tattoo.

/proc/custom_sprite_salon_open_draftReopens a retained draft for its artist, rebinding the artist's body and tool.
