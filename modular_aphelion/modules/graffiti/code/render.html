modular_aphelion/modules/graffiti/code/render.dm

GRAFFITI_ICON_CACHEMost icons the art icon cache keeps, and the glow mask cache too: 128 dense art icons of 4,801 bytes take 0.6 MB, and 128 glow masks of 6,930 bytes 0.9 MB, as measured.
/proc/graffiti_blank_iconReturns a new transparent icon one or two tiles wide.
/proc/graffiti_draw_iconDraws pixels on a new icon as horizontal runs, one DrawBox() for each run of one colour.
/proc/graffiti_drawn_colorsReturns colours as placed graffiti draws them, in their real alphas: opaque ones at GRAFFITI_ALPHA_CEILING, so the surface shows through, and translucent ones at their own, which is below it. None draws above the ceiling.
/proc/graffiti_art_iconReturns an art drawn as an icon, which every tile showing that art shares. Its paint shows at its real alpha (graffiti_drawn_colors()).
/proc/graffiti_glow_iconReturns an art's glow mask: white wherever its paint glows, as opaque as the paint is drawn there.
/proc/graffiti_art_glow_kindReturns which of an art's painted pixels glow, which decides its emissive overlays.
/proc/graffiti_emissive_overlaysReturns the overlays that light an art's glowing paint on the emissive plane and let its other paint block the glow of whatever lies beneath it.
/proc/graffiti_new_sheetReturns a new sprite sheet for icons of one width. BYOND can't remove a state, so the blank's own transparent state, "", stays beside the states added to it.
/proc/graffiti_sheet_addAdds an icon to a sprite sheet as a state of its own, replacing any state of that name.
/proc/graffiti_sheet_pathReturns where one of a map's sprite sheet files lives.
/proc/graffiti_file_keyReturns text made safe to name a file or directory with.
