GRAFFITI_WORK_COMPOSITEDeferred work for SScustom_sprite_work: recomposite a freehand session's surface. The custom sprite editors' own work flags take the bits below it.
/datum/custom_sprite_editor/graffitiThe graffiti editor: the custom sprite editor's shell on a graffiti piece, whose canvas, tools and history it reuses.
/proc/graffiti_editor_forOpens a graffiti editor for a player, ending any editor they already have. A surface session shakes the can.
/proc/graffiti_library_write_dueWhether a player may write their graffiti library now, starting a second's wait if so. Each write rewrites and checks the whole file, so the account's saves, imports and exports share the wait, which is kept beside its style transfer cooldowns, and each write lengthens it by its cost (graffiti_library_paced()).
/proc/graffiti_library_pacedPaces an account's next graffiti library write by the one just made: a player's waits GRAFFITI_LIBRARY_WRITE_PACE times as long as it took, and at least a second, and a change the server makes is held back as long.
/proc/graffiti_library_write_waitReturns how long until an account's graffiti library may be written again.
