/proc/set_owned_masked_leg_iconsPublish or evict a finalized masked-leg pair and its exact native dimensions together. The caller must finish icon mutation before publishing. Existing cache entries are immutable. Retain the replacement before releasing the old pair, including when they share icons. Raw cache writes/removals must use this proc so metadata does not outlive its owning cache.
/proc/clear_owned_masked_leg_iconsRelease owned metadata when the existing masked-leg cache is explicitly cleared.
WORN_EMISSIVE_UNDERLAYSTraversal selector for underlays, visited first. The two selectors are contiguous, so a range visits both without allocating a selector list.
WORN_EMISSIVE_OVERLAYSTraversal selector for overlays, visited after underlays.
WORN_EMISSIVE_VISIBLE_RESULTThe shared out-parameter's only slot; the proc's ordinary return value holds the emissive tree.
/proc/prepare_bodypart_overlaysPrepares the final bodypart or hair slot, where direct glow/blocker masks already have their centering and height adjustments. Each mask moves inside a neutral emissive boundary so rotation does not depend on icon size; masks sharing a plane and layer share one boundary. Plain visible sprites sharing a layer share one holder. Only the mob's top-level overlays count toward MAX_ATOM_OVERLAYS, and a matrixed accessory otherwise spends a sprite and a mask per colour slot on every layer it draws.
/proc/is_plain_bodypart_maskWhether a bodypart appearance is a standard glow/blocker sprite that can move into a shared emissive boundary. Inset husk blood, other composite effects and prepared boundaries keep their own roots.
/proc/is_plain_bodypart_spriteWhether a bodypart appearance draws the same nested in an unshifted holder as it does on the mob: floating, default blending, and not reaching past its parent with KEEP_APART or RESET_* flags. Iconless holders such as inner ears and MOD textures qualify; their contents are unchanged.
/proc/split_worn_emissive_branchesReturn the emissive-only tree, or null if nothing changed. visible_resultWORN_EMISSIVE_VISIBLE_RESULT receives the visible tree (null for a moved mask leaf). The caller reuses this single return slot throughout the traversal; each node consumes its child's result immediately. Unchanged branches retain their original appearances and allocate no lists. Nested cross-plane masks escape the mob's KEEP_TOGETHER group. Moving the plane boundary to a sibling root lets BYOND inherit the mob transform normally, without baking a pose into the cache. Only floating equipment masks are moved; absolute-layer effects and other planes retain their behavior.
