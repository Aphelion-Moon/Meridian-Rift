/datum/robotic_style/recolorableA finish drawn on the Muscular outline in up to four player colours (paint, accent, frame, lights).
AUGMENT_PAINT_MATRIX_CACHE_SIZEHow many matrices augment_paint_matrix() keeps before it starts over.
/proc/augment_paint_matrixReturns a recolourable finish's colour matrix for one of its packed states: numeric and 4x4, rows red, green, blue, alpha, as Nova's naga tail builds its (constrict.dm). Never rows of colour strings, which map_colors_inferred() can't flatten for the drawn character preview. Each is built once and kept, by colours, state and alpha, until AUGMENT_PAINT_MATRIX_CACHE_SIZE are kept; then the cache is emptied before the next is added, since a player can apply colours without end. A matrix is cheap to build again, and a limb keeps the one it was given.
/proc/sanitize_augment_colorsReturns colors lowercased when it is four "#rrggbb" colours run together, else null. It runs only as a save loads and on the editor's actions, so its regex is made each time rather than kept.
