# Inventory artwork

Generated using the built-in imagegen tool. These are pilot sample assets, referenced only by the explicitly spawnable `grid_sample` item subtypes. Source PNGs retain transparency; the inventory hook caches a proportional pixel-scaled version (maximum 96 pixels) for the HUD. World and in-hand sprites are unchanged.

## lighter.png

Create one isolated inventory sprite for a retro pixel-art space-station game. A small red metal flip-top pocket lighter, closed, upright. Designed for a 32 by 32 pixel inventory cell. Crisp pixel art with a limited palette, dark one-pixel outline, restrained highlights and shading, clean readable silhouette. Orthographic front view, no floor, no cast shadow, no other objects, no lettering. Transparent alpha background, centered fully visible object with a small transparent margin. It must be usable as a game asset downsampled with nearest-neighbor filtering.
