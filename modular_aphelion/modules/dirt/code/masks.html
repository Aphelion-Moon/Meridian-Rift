modular_aphelion/modules/dirt/code/masks.dm

DIRT_MASK_SOLIDHow much of a pixel a role's run covers, out of 255 (dirt_role_runs()). Haze is film at half.
DIRT_CARRY_PIXELSHow many of a wag frame's pixels one piece of a mask job carries from the still tail (/datum/dirt_tail_carry). The first piece also works out the frame's coordinates.
/datum/dirt_splatOne piece of dirt on a carrier, at a level. It's a variant of a zone's mess, or of a general deposit, a cause's dirt in a material. More shots on the zone raise a mess splat's level. Past the top level, another splat starts.
/proc/dirt_splat_materialsReturns each splat's material in order, as dirt_merge() takes them, or null when every one is mess.
/proc/dirt_holds_depositsReturns whether some splats hold a general deposit. A general deposit draws on a body's dirtier side, and on a bare body it draws its painted designs.
/datum/dirt_mask_requestWhat a surface's masks are made from: the body they're drawn on and the splats on it. Requests with the same mask_key() share their masks, so bodies drawn from the same sprites with the same splats draw the same icons. A request is made once and never changed. It keeps copies of the splats. So a splat that levels up or lands while its masks wait in the queue changes neither the key nor what's drawn under it.
/datum/dirt_mask_jobMakes a request's masks a piece at a time (next_piece()). While it waits, SSdirt.mask_jobs holds it under its key, so a body asking meanwhile waits for it (wait()) rather than queueing it again.
/proc/dirt_cover_fadesReturns how near a mask's pixels lie to what's worn over them, where they fade out: alist(index = 1 beside it, or 2 one pixel further), for the pixels drawn that it leaves bare. Steps are up, down and across.
/proc/dirt_mask_directionsReturns the directions a mask is made in, in the order its pieces go. You should NEVER modify it.
/proc/dirt_thickness_codeReturns the code a thickness packs as in /datum/dirt_pixels/proc/drawn(), from 0: its place among the thicknesses packed so far this round. Thicknesses come from a handful of values, because every thickness dirt is drawn with is a constant. A thickness worked out per pixel would use up the codes.
/proc/dirt_packed_thicknessesReturns the thicknesses packed so far, indexed by code + 1 (dirt_thickness_code()). You should NEVER modify it.
/proc/dirt_pixels_from_drawnReturns a raster unpacked from its text. Given a general deposit's limbs, it keeps the pixels on them alone. A carrier holds a deposit only on the limbs it showed on as it landed. A pixel off them is never written and never in drawn_indexes, so every merge reads it as a pixel with no role. Limbs 0 or every limb keep every pixel. A merge reads the text itself instead (dirt_merge()).
/proc/dirt_drawn_indexesReturns the indexes of the drawn pixels in a packed text (/datum/dirt_pixels/proc/drawn()), in row-major order.
/proc/dirt_drawn_rolesReturns the roles runs are drawn in, one to a pixel, in the order they're baked. Haze is drawn as film at half (dirt_role_runs()). You should NEVER modify it.
/proc/dirt_shown_runsReturns a surface's runs, as dirt_role_runs() lays them: alist(material = alist(DIRT_ROLE_* define = alist(direction = runs))), each material as a splat stores it.
/proc/dirt_baked_iconReturns runs baked into one four-direction RGBA icon on a blank state (dirt_baked_frames()), or null when they draw nothing. It's registered in the resource cache (bulge_register_icon()).
/proc/dirt_baked_framesReturns runs drawn on a blank in each direction, alist(direction = icon), unregistered, or null when they draw nothing. Each run is one DrawBox() in its material's tint colour for its role (dirt_material()). Its alpha is the tint's times the run's level, rounded to 8 bits. A wet material's runs (sweat) take no colour, because the cloth darkens under them in its own colour (dirt_wet_image()).
/proc/dirt_runs_keyReturns an MD5 of what runs draw, the same for runs that draw the same pixels. It hashes each material's name, then its roles' runs in each direction, in a fixed order, with their levels.
/proc/dirt_role_runsAdds a mask's horizontal runs in one direction to each material's roles, each run list(icon y, first icon x, last icon x, level). A run is one material's pixels in one role, side by side in one row at one level. The level is how much of each pixel it covers out of 255: DIRT_MASK_SOLID, or DIRT_MASK_HALF for haze, which is drawn as film. A pixel beside what's worn over it keeps a share of its level: its fade ring over DIRT_FADE_RINGS + 1. A run goes in its list as it ends, when its role's next run starts or after the last pixel. A list is made as its first run goes in, so equal masks give equal runs.
/proc/dirt_runs_targetReturns the list that one material's runs in one role and one direction go in. It's made as its first run goes in (dirt_role_runs()).
