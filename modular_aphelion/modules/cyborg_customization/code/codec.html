#define
CYBORG_CODEC_VERSION

The compact save text for one character slot, kept as a string in cyborg_customization.json.

A slot is a JSON array of [format version, active layout, presets, model defaults, active model, active preset]. Presets are flat [name, layout, chassis] triples and model defaults flat [chassis, layout, linked preset] triples. A layout lists its parts in cyborg_layout_supported_slots() order, 0 for an untouched part. A part is [mask, values...]: each mask bit marks a field that differs from its default, and its value follows in bit order unless the bit says it all. Overrides are flat [key, override] pairs, the key an index into cyborg_layout_supported_advanced_keys(). An override is [header, values..., arousal states]: the header's low six bits say which fields it has, the next six which of those differ from what the editor fills a new override with, and only those values are written. Decoding rebuilds the nested tree and runs it through cyborg_layout_normalize(), so a reload matches the old format. Unset trailing fields are left out everywhere. Appending to these orders is fine; reordering breaks saved slots. Save text format version, the first value in every slot's text
