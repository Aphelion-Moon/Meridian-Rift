bridle
/obj/item/clothing/mask/bridle

A three-colour horse bridle. Lowered blinders darken the wearer's sight and a set bit muffles their speech. Toggled with the action buttons or alt-click, or by others from the strip menu. Securing the straps locks both in place.

Vars

modeBRIDLE_BLINDERS if the blinders are lowered, BRIDLE_BIT if the bit is set. Only set_mode() changes it.
straps_lockedWhether the straps are secured, locking the blinders and bit.

Procs

cycle_modeCycles through none, blinders, bit and both.
set_modeSets the blinders and bit to match new_mode. Returns FALSE if the straps are secured.
set_muffledAdds or removes the muffles_speech element. The element only hooks the wearer on equip and drop, so a worn bridle hooks and unhooks them here.
strip_adjustThe strip menu's "Adjust bridle": warns the wearer, waits the strip delay, then cycles the mode once and logs it. Secured straps refuse without the wait.
strip_adjustableWhether user can adjust the bridle on wearer's face from the strip menu. Needs the wearer's sex toy preference and the user's ERP preference.
tell_movedTells user they moved part, and tells the wearer, if someone else, what changed and who did it.
