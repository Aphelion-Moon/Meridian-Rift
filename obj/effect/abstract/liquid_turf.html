proc
get_clip_filter
(icon_file, mask_state)

Returns get_alpha_filter() for a mask, or null when the mask is fully opaque and so clips nothing.

Only for art under the exact-art RULE in the art contract: the mask's size, and partly clear pixels, if any, at 0 or 255 per channel. A filter passes those and opaque or clear pixels exactly, but draws other partly clear colours a level off, so leaving it out would change them.

Arguments:

  • icon_file: The DMI holding the mask.
  • mask_state: The mask's icon state.

proc
get_fire_state
(hotspotted)

Returns the fire state this liquid's mix supports.

A mix burns only while more than REQUIRED_FIRE_FLAMMABLE_SHARE of it is flammable and its power per unit beats REQUIRED_FIRE_POWER_PER_UNIT. Each state above small then needs both its LIQUID_FIRE_POWER_* power per unit and its LIQUID_FIRE_UNITS_* flammable units. Power per unit caps how fierce the mix burns, and the flammable units left shrink the fire as it burns out.

Arguments:

  • hotspotted: TRUE when something is igniting us. Without it, a liquid that isn't burning stays out.

Returns:

  • A LIQUID_FIRE_STATE_* define, LIQUID_FIRE_STATE_NONE when the liquid won't burn.

proc
ignite_fire_visuals
(tier, loop)

Lights this tile's fire: makes the flames and their emissive copy, plays the ignite once on both, and starts the smoke when the ignite ends.

The ignite is a flick, which the server times, so a client that first sees the tile mid-ignite sees the rest of it and then the loop. NEVER show the ignite through icon_state: each client would start it over at first sight.

Arguments:

  • tier: The fire art's tier, from get_fire_tier().
  • loop: This tile's fire loop, from get_fire_loop().

proc
make_surface_texture
(texture, junction, mask_state)

Returns this tile's slice of a world-anchored surface texture, clipped to the pool by an alpha filter.

A fully opaque mask leaves tone, grit and chunks slices unfiltered (get_clip_filter()), and a weight mask of one alpha becomes the slice's own alpha.

Arguments:

  • texture: The slices' state prefix in liquid_surfaces.dmi.
  • junction: This tile's smoothing junction. A lone puddle (0) takes the texture's fixed slice, when it has one.
  • mask_state: A liquid_surfaces.dmi weight state to clip by. Null clips by this tile's base state.

proc
process_fire
()

Runs one fire run on this tile: spreads the fire, burns its fuel and heats the tile.

Each flammable reagent uses up its liquid_fire_burnrate, then the fire state follows what's left. So the fire steps down as it burns out, and leaves processing once it's out.

proc
reagents_to_text
()

Creates a string of the reagents that make up this liquid.

Puts the reagent(s) that make up the liquid into string form e.g. "plasma" or "plasma and water", or 'plasma, milk, and water' depending on how many reagents there are.

Returns the reagents list string or a generic "liquid" if there are no reagents somehow

proc
update_fire_visuals
()

Shows this tile's fire as fire_state asks: lights it, swaps its tier, or puts it out.

The flames, their emissive copy and the smoke are holders in vis_contents, so a tier change only swaps their icon_states and never rebuilds the liquid's overlays. Every looping state runs on one clock per client, so a swapped loop keeps time.

proc
update_from_reagents
(force_redraw)

Works out this liquid's depth, colour, alpha and surface from reagent_list, and redraws its overlays once if its depth or surface changed.

Arguments:

  • force_redraw: TRUE redraws even when neither changed, for a liquid that isn't drawn yet.
