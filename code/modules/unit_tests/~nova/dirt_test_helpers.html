/proc/standing_imagesReturns what a body draws at one of its overlays_standing layers as a list, though tg keeps a lone image there bare.
/proc/height_filter_mapsReturns the height maps on an image's displacement filters, in the order they're drawn, each list(the map's icon, the filter's size). Its filters are read, not its filter_data, which the copy of it kept for drawing leaves behind.
/proc/dirt_parity_corpusReturns the parity corpus beside the dirt tests (dirt_corpus.json), decoded. It's compiled in, since CI's test world is deployed without code/.
/proc/dirt_test_seed_variantSeeds BYOND's random number generator so that the next variant drawn is variant. Returns a number to seed it with after that draw, so the rest of the run stays random. A new splat's variant is drawn at random, and a test that checks its pixels needs a set one. The call made next must draw the variant before any other random call, as dirt_land() and dirt_fresh_variant() do.
/proc/dirt_test_seed_rollSeeds BYOND's random number generator so that the next roll passes one chance and fails another. Returns a number to seed it with after that roll, so the rest of the run stays random. A source rolls its own chance, and a test needs a set outcome. The call made next must roll before any other random call, as dirt_source_land() does.
/datum/unit_test/dirt_testThe dirt tests that draw dirt on bodies, with the helpers they share: genitals built from DNA as a real character's, taurs, and reads of what a body draws.
