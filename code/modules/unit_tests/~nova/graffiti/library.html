/proc/graffiti_library_test_resetPoints the graffiti library directory at root, then forgets the test account's library and its write pacing and deletes the scratch directory, so a test starts and ends with no library files.
/datum/unit_test/graffiti_library_capsA library holds GRAFFITI_LIBRARY_CAP pieces and the Unfinished slot through a reload from its file. Each write paces the account's next player write by its cost. At the cap it refuses a new piece and a Keep but still replaces a saved piece, and a stored piece that no longer validates is dropped when the file loads. The library loaded after a purge is empty under a newer revision, so a window still showing the purged one is sent the empty one.
