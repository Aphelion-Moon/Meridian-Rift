DIRT_MODULOvalue modulo divisor with the divisor's sign, as the reference generator takes it. BYOND's % and %% keep the value's, and tg's WRAP() adds a clamp and a test it doesn't need. Exact for whole numbers from -(2^24 - divisor) up to 2^24. It reads value twice, so pass it a variable, never a call such as draw().
DIRT_WRAP_DEGREESAn angle in degrees turned into the range -180 up to 180, never 180, as the reference generator wraps one. Exact from -540 up to 540. A difference of two thetas stays in that range, except against a painted design's point copied round the body (dirt_painted_around()), which can reach about -546. That one still wraps past any reach it's compared with, so it changes no pixel. It reads degrees up to three times, so pass it a variable.
